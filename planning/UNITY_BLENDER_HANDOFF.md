# Catatan tahap visual berikutnya

Instruksi pengguna, 21 September 2026: animasi dan desain 3D akan dikerjakan selanjutnya menggunakan Unity dan Blender.

- Tahap sekarang tetap mengerjakan mekanik, data karakter, quest, progression dan UI prototipe Three.js.
- Tahap Blender: desain mesh, rig dan animasi berdasarkan Guide Karakter, World Bible dan arah visual yang telah dicatat. Aset prosedural sekarang adalah placeholder.
- Tahap Unity: integrasi dan pengujian animasi/aset pada tahap visual berikutnya. Versi editor, render pipeline, format ekspor dan target hardware ditentukan saat pekerjaan itu dimulai; belum dibuat proyek Unity.
- Pertahankan ID karakter, nama skill, event aksi/hasil/status serta data anchor sebagai kontrak antara logika dan presentasi. Referensi implementasi saat ini: `src/combat.js`, `data/awaken.js`, `data/nirwasita-stats.js`.
- Instruksi visual ini belum menyatakan pemindahan seluruh produk dari Three.js ke Unity. Keputusan tersebut tetap terpisah dari pembuatan animasi/aset.

Sumber konten tetap dibatasi pada kategori Markdown yang telah dipilih pengguna. Review lore dan budaya serta arah karakter tetap berlaku pada aset final.
